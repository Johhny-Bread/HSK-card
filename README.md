# HSK 단어 카드

신HSK(3.0) 4·5급 단어 2,000여 개를 폰에서 짬날 때 외우는 카드 앱이에요.
설치나 로그인 없이 브라우저에서 바로 쓰고, 홈 화면에 추가하면 앱처럼 열려요.

## 기능

- **간격 반복 복습**: 모르는 단어는 같은 세트에서 다시, 맞힌 단어는 1·2·4·7·15·30일 간격으로 다시 나와요. '알고 있음'을 누른 단어는 다시 나오지 않아요.
- **한 세트 약 10장, 2~3분**: 새 단어 소개, 뜻 고르기, 예문 빈칸, 떠올리기 카드가 섞여 나와요.
- **모든 단어에 예문**: 예문 속 한자를 누르면 단어별 병음과 뜻이 나와요. 발음 듣기는 기기에 내장된 중국어 음성을 써요.
- **접속사 정리**: 不但…而且…, 与其…不如… 같은 짝 패턴 28개를 따로 모아 공부할 수 있어요.
- **헷갈리는 한자**: 비슷하게 생긴 한자 54개 그룹과 '빈칸에 들어갈 한자 고르기' 연습.
- **약한 단어·오늘 푼 단어 목록**, 약한 단어 짝맞추기, 이전 카드로 되돌리기.
- 진도는 각자 기기의 브라우저에 저장돼요. 브라우저 데이터를 지우면 진도도 지워져요.
- 한 번 열고 나면 인터넷이 없어도 열려요.

## GitHub Pages로 공개하는 방법

1. GitHub에 로그인하고 오른쪽 위 **+** → **New repository**를 눌러요.
2. 이름을 정하고(예: `hsk-cards`) **Public**을 선택한 뒤 **Create repository**를 눌러요.
3. 새 저장소 화면에서 **uploading an existing file** 링크를 눌러요.
4. 이 폴더의 파일을 전부 끌어다 놓고 **Commit changes**를 눌러요.
   - `index.html`, `words.js`, `gloss.js`, `hanzi.js`, `sw.js`, `manifest.webmanifest`, `icon-512.png`, `apple-touch-icon.png`, `README.md`
5. 저장소의 **Settings** → **Pages**로 가서, **Branch**를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 눌러요.
6. 1~2분 뒤 같은 화면 위쪽에 주소가 나와요. 보통 `https://아이디.github.io/hsk-cards/` 형태예요.

### 폰 홈 화면에 추가

- 아이폰 사파리: 공유 버튼 → **홈 화면에 추가**
- 안드로이드 크롬: 오른쪽 위 ⋮ → **홈 화면에 추가** 또는 **앱 설치**

### 파일을 고쳐서 다시 올릴 때

`sw.js` 맨 위의 `VERSION` 값을 바꿔 주세요(예: `hsk-v1` → `hsk-v2`). 바꾸지 않으면 이미 열어 본 사람의 폰에는 예전 파일이 계속 보일 수 있어요.
